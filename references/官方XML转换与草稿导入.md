# XML 转换与草稿导入

## 编排结构化 Markdown

- 将已核对的技术申请内容放入对应分册。说明书的标准三级标题为「技术领域」「背景技术」「发明内容」或「实用新型内容」「附图说明」「具体实施方式」。摘要使用普通段落。实用新型须有说明书附图；两类技术申请有图时均从图1连续编号。
- 文本下标和上标可写为 `s<sub>1</sub>` 和 `x<sup>2</sup>`。表格用管道分列，保留首行和每行的列数。段落内需要显式换行时，在行末加两个空格。
- 水平分式和下标写在独立的 `math` 围栏内，例如 `v=\frac{s_{2}−s_{1}}{Δt}`。用 Unicode 写 Δ 等符号，用花括号标出分式参数和下标。生成的 DOCX 中可编辑这类公式，XML ZIP 中对应为图片。
- 附图节每幅图单独成段，例如 `![图1](figures/sampling.png "width-mm=120")`。图片相对路径从 Markdown 所在目录解析，宽度用毫米表示，高度按图片比例计算。
- 遇到不支持的 Markdown 对象时，先按诊断定位源段落。涉及技术含义的对象转入模板 DOCX 并使用适用的编辑器。保留原对象以便对照。

外观设计的工作稿示例：

```markdown
# 杯垫

## 外观设计图片或照片

![主视图](figures/front.png "width-mm=80")

## 外观设计简要说明

产品用途：用于承托杯具。

设计要点：在于图样的形状及图案。

最能表明设计要点的图片或照片：主视图

省略视图及原因：背面无设计要点且在使用时不易看见。
```

每个视图单独成段。按已确认的简要说明补充其他纯文本段落，保留段落顺序。相似设计的「基本设计：设计1」及代表图字段填对应的完整编号或图名，行尾省略句号。对应 DOCX 在简要说明节首段写「产品名称：杯垫」，其后使用同样的字段和段落。在图片或照片节中依次写入独立嵌入位图及紧随其后的完整视图名。优先在本 Skill 生成的 DOCX 副本中继续编辑。

## 准备五书 DOCX

遇到字符样式缺失或循环引用，定位诊断指出的段落，在工作副本中修正字符样式继承关系，或按审定稿直接设置上下标。重转后逐个核对数字与相邻单位、变量及权项限定。

- 每项权利要求独立成段，在正文中写出顺序编号，例如「1.」。说明书首个非空段落写发明或实用新型名称，标准章节标题各占一段。保留各分册的模板节页眉。
- 把每幅附图以内嵌位图放在独立段落，下一段仅写「图1」等对应图号。浮动图形、带裁切或旋转的图件、合并单元格以及超出分式和下标范围的原生公式，按对应对象和位置交给官方编辑器处理。
- 沿用模板工作稿中的图片、表格和公式。生成后查看 JPEG 中尺寸最小的公式字符和附图标记，再核对对应的官方分册显示。

## 在 Windows 使用官方编辑器

准备 Windows 10 或以上、Office 2013 或以上或 WPS 专业版 2015 或以上，安装国家知识产权局的 Word 转 XML 编辑器。用官方安装包中的 EXE 启动安装，按需确认加载项。打开 DOCX 后，在「专利处理」选项卡显示高级菜单。官方工具页同时提供 Word 和 WPS 操作手册及常见问题。 [编辑器及操作手册](https://cponline.cnipa.gov.cn/GzfwYwblGlwhTMVC/GzfwYwblGlwhT/selectToolsById?weihuRid=157)

1. 打开[官方五书模板](../assets/WORD转XML编辑器五书模板文件.docx)的工作副本。每个分册使用模板对应的节和页眉。完整稿件包含权利要求书、说明书、摘要及适用的说明书附图节。有图时把图件收进说明书附图节，在请求书中用图号指定其中一幅作为摘要附图。
2. 确认节页眉、权项编号、图号、标题和公式均可在 DOCX 中辨认。依次点击「一键添加标记」和「五书 XML 转换」，在工具的 XML 检查窗查看各分册。使用「制作压缩包」，在当前 DOCX 同级目录取得官方 ZIP。
3. 安装并启动官方 XMLPREVIEW 组件。如果提示预览服务不可用，按其官方说明运行启动脚本，再从 Word 点击「预览」生成分册 PDF。ZIP 生成成功与预览服务可用是两项独立结果。 [预览组件下载入口](https://cponline.cnipa.gov.cn/GzfwYwblGlwhTMVC/GzfwYwblGlwhT/selectToolsById?weihuRid=240)

处理外观设计时，在编辑器的「新建专利」选用对应模板，将两册按原稿编入，核对视图名并按需要标记扉页图片。用对应的标记、XML 转换和打包入口，检查取得的两册及图片引用。 [图片或照片转换模板](../assets/外观设计图片或照片模版.dotx) · [简要说明转换模板](../assets/外观设计简要说明模版.dotx) · [编辑器及操作手册](https://cponline.cnipa.gov.cn/GzfwYwblGlwhTMVC/GzfwYwblGlwhT/selectToolsById?weihuRid=157)

交接给用户转换时，提供同一版本的工作稿、对应的预期分册和需重点复核的对象。请用户返回原始 ZIP 及官方分册预览，说明已转换的稿件版本。复核第一处标题、最后一段正文和关键图表公式，确认实际读取的是同一版。

## 检查 XML 包

外观设计采用带 ICC 的 CMYK 图样时，对照按源配置显示的图样和 ZIP 中的 sRGB JPEG，检查设计要点涉及的色块。转换器使用包内固定的 sRGB 输出配置。若诊断提示缺少或无法使用源配置，保留该视图原件，请用户确认用于转换的 sRGB 副本并记录对应关系。 [sRGB 输出配置](../assets/sRGB-v4.icc) · [配置来源与 CC0 许可](https://github.com/saucecontrol/Compact-ICC-Profiles)

| 包内文件 | 预期内容和检查 |
| --- | --- |
| `100001/100001.xml` | 权利要求书。检查权项数量、顺序、编号和引用。 |
| `100002/100002.xml` | 说明书。检查名称、章节、正文、有依据的条件及数值。普通表格可见于 `tables/table`，应逐项核对行列与单元格。公式图片可见于 `maths/img`。 |
| `100003/100003.xml` | 实用新型和有图发明的说明书附图。检查 `figure` 图号与 `figure/img` 的文件引用、附图标记和对应正文。 |
| `100004/100004.xml` | 说明书摘要。检查正文及特殊字符。 |
| `130001/130001.xml` | 外观设计图片或照片。按 `authorization/image` 的顺序核对各图。用 `physical-name` 定位同目录 JPEG，用 `logical-name` 核对完整视图名及归属。确认简要说明所指的代表图为唯一 `fengpi-flag` 等于 `1` 的图，其余为 `0`。逐一检查图片比例和清晰度。 |
| `130002/130002.xml` | 外观设计简要说明。按 `cn-design-application-body/cn-brief/p` 的顺序核对产品名称、用途、设计要点和代表图，以及适用的保护部位、色彩、视图省略、基本设计、套件或界面说明。 |

解读 ZIP 时核对分册及其 XML 可读性，将每个图片引用定位到包内实际资源，例如 `100002/100002_1.jpg`。用官方分册预览对照审定稿，逐项核对内容和显示。发明和实用新型的 XML 根元素为 `cn-application-body`。 [XML 上传清单](https://www.cnipa.gov.cn/art/2025/11/12/art_75_202551.html) · [官方数据标准](https://cponline.cnipa.gov.cn/GzfwYwblGlwhTMVC/GzfwYwblGlwhT/selectToolsById?weihuRid=248)

- **识别失败或分册不完整。** 检查申请类型、Markdown 分册标题或 DOCX 节页眉，修正段落或视图、权项标记后重新转换。无图发明按三个正文分册检查。
- **图片或公式引用缺失。** 检查 Markdown 的图件路径及公式围栏，或检查 DOCX 是否完整嵌入图件和对象。重新转换并保留转换器生成的目录结构，用新 ZIP 重做引用与预览检查。
- **公式、矢量图或复杂表格无法转换。** 按手册先试原生对象。若工具无法识别，在工作副本中将对应对象转成清晰图片，重做转换，对照源文核验符号、内容和尺寸。检查引用的图片实际显示完整。
- **本地 DTD 诊断。** 使用 DTD 校验时同时取得该标准目录中的配套实体。libxml2 可能对附图分册 `100003` 报 `DTD_CONTENT_NOT_DETERMINIST`，该诊断指向官方 DTD 的 `cn-drawings` 内容模型。记录诊断，再核对官方包、引用和官方预览的实际结果。

## 授权后验证网页版草稿

分别收集当前草稿和交付 ZIP 的证据。例如，逐页上传的图样均已重开核对，且请求书、附件和整包预览通过，可记录「当前网页草稿可提交。交付 ZIP 已通过本地分册检查，直接导入待核验」。若编辑器回显七张图而整包预览只有六张，记录遗漏视图的全名和归属，保留「网页草稿待核验」。

1. 核对授权的案卷和文件，由用户登录并完成身份认证。在「国家申请」选择对应申请类型，进入「未提交业务 → 新申请办理」。发明和实用新型可从「权利要求书 → 上传」选择对应稿件的 XML ZIP。外观设计从当前案卷提供的文书导入入口上传。有图样页和简要说明页而未找到文书导入入口时，可从 `130001` 取出 JPEG 并按图名放入对应节点，对照 `130002` 填写简要说明。记录组稿结果和待核验的 ZIP 导入。请求书「附加文件」栏的上传用于附加文件。
2. 在对应请求书页签核对申请名称和身份字段。对实用新型及有图发明，在「摘要附图」栏指定现有图号，例如图 1 填 `1`。对外观设计核对相似设计项数、成套产品件数及适用的局部选项，对照简要说明、代表图和图片或照片分册。
3. 适用时在「外观设计图片或照片」页签选择对应节点，通过「上传三维」或「上传动画」选择授权的附件。检查页面支持的格式和大小。留在图样页签，点击案卷工具栏的「保 存」并确认成功。返回列表重开草稿后，逐图检查名称和归属，点击对应媒体节点检查显示或播放。记录入口、上传反馈和保存回显。
4. 进入整包预览，核对请求书、分册与附件。对照图样编辑器核验预览 PDF 的图名、数量和归属，尤其检查组合状态参考图。记录仅在编辑器回显的图样及其原位置。若页面显示校验问题，记录受影响字段及位置，交由用户补正。正式提交由申请人另行操作。 [办理系统网页版操作手册，第 4.2.1 至 4.2.3 节](https://www.cnipa.gov.cn/module/download/downfile.jsp?classid=0&filename=f5f783331b5e48d79af2b1295d8fa03d.pdf)
