# 申请文件与核验

## 请求书填报

按类别查阅包内请求书，用申请时的网页版核对实际必填项。纸面表格用于核对字段，电子请求书在系统中按对应类别填写。居民身份、联系人和声明按本案事实确认。 [发明 110101](../assets/110101发明专利请求书.doc) · [实用新型 120101](../assets/120101实用新型专利请求书.wps) · [外观设计 130101](../assets/130101外观设计专利请求书.wps) · [国知局表格目录](https://www.cnipa.gov.cn/col/col192/index.html?pageNum=0&uid=8599)

| 项目 | 整理和核对 |
| --- | --- |
| 申请名称 | 发明、实用新型的名称与说明书首部一致。外观设计的产品名称与简要说明及所示产品一致。 |
| 申请人 | 核对申报顺序、姓名、地址、邮编、身份证件号码及系统要求的其他字段。申请人身份及申请权来源由用户确认。 |
| 发明人或设计人 | 技术类填写发明人，外观设计填写设计人。按系统提示核对顺序、姓名、国籍或地区、证件及公布安排。 |
| 代表人及联系人 | 在系统要求时从已确认的申请人中指定代表人，记录已确认的联系人及联系方式。多个申请人未委托代理机构时，请求书未另有声明的，以第一署名申请人为代表人。 |
| 申请文件及附加文件 | 按实际随案文书列出名称，以及系统要求的份数、页数、权项数等。必要时按案件事实确认专门附件或声明的适用性。 |
| 摘要附图 | 实用新型及有附图的发明指定一幅现有说明书附图。记录与附图分册对应的实际图号。 |
| 外观设计选项 | 根据已确认材料核对相似设计项数、成套产品件数及局部设计选项。代表图按完整视图名称写入简要说明。分别记录适用的三维模型、动画所对应的设计或视图。 |
| 其他条件字段 | 涉及优先权、非普通申请事项或特殊附件时先记录适用情况。需确认的声明交由用户选择，签字或电子认证由申请人完成。 |

申请人、发明人或设计人和代表人分别核实。对用户不希望写入本地的证件值，记录「由用户在系统填写」和确认情况。尚未确认的字段列为待补，说明对草稿核验的影响。内部溯源、问题清单及证据说明留在核验记录。 [专利法第二十六、二十七条](https://www.cnipa.gov.cn/art/2020/11/23/art_97_155167.html) · [专利法实施细则第十四、十七和十九条](https://www.cnipa.gov.cn/art/2023/12/21/art_98_189197.html)

## 正式文书细则

### 说明书

- 通常按技术领域、背景技术、发明内容或实用新型内容、附图说明和具体实施方式组织。无图发明省去附图说明。发明或实用新型内容交代技术问题、解决方案及有依据的效果。引用背景文献时采用交底书明确提供并可核实的资料。
- 保留原材料规定的适用条件和实施方式，给每个参数保留数值、单位、边界值及其适用对象。若正文用图、表或公式解释方案，其编号、符号、数据及引用也纳入复核。
- 正文用客观、清楚的技术陈述。核对申请名称与请求书一致，并清理宣传性表述及「如权利要求所述」一类引用。

### 权利要求书

- 依照申请人已披露的拟保护范围确定每项权利要求。独立权利要求应包含解决技术问题所需特征。适合区分共有必要特征和区别特征时采用前序部分和特征部分，具体表述以源材料披露为据。
- 从属权利要求的引用部分写明在前权项的编号和主题，限定部分增加相应的技术特征。多项从属权利要求择一引用在前权项，且不能作为另一项多项从属权利要求的基础。
- 使用与说明书一致的术语，按阿拉伯数字顺序编号。公式按可识别的数学式或化学式处理。必要时用括号标出附图标记，权项中的文字本身应能表达技术限定。

### 摘要和附图

- 摘要写明发明名称、技术领域、技术问题、方案要点和主要用途。正文包括标点在内不得超过 300 字，采用客观陈述，分册名称由模板页眉提供。
- 说明书附图按「图1、图2……」顺序编号，正文和附图的标记双向对应。同一部件采用相同标记。图中保留必要的文字，查看实际尺寸下的图题、线条及标记。
- 摘要附图从说明书的已有附图中选择，通过请求书字段指定。保留被指定图在说明书附图分册中的原有位置和编号。
- 实用新型附图须清楚展示受保护产品的形状、构造或其结合。检查是否误用照片、工程蓝图、仅展示现有技术的图或仅展示性能的曲线。核对结构线条、附图标记及对应的实施方式。

文书组织和表述主要依据《专利法实施细则》第二十至二十六条及《专利审查指南》第一部分第一章、第二部分第二章。 [专利法实施细则](https://www.cnipa.gov.cn/art/2023/12/21/art_98_189197.html) · [专利审查指南及修订文本](https://www.cnipa.gov.cn/art/2025/11/14/art_99_202568.html)

### 外观设计

| 情形 | 核对 |
| --- | --- |
| 整体设计 | 根据产品及设计要点核对所需的正投影图和立体图。附加参考图与保护视图区分命名。 |
| 局部设计 | 产品名称写明局部及其所在整体。核对整体视图是否清楚标示位置、比例与保护部分。采用虚实线以外的表示法时在简要说明写明保护部位，必要时说明点划线边界。代表图包含要求保护的局部。 |
| 相似设计 | 同一产品的设计按「设计1主视图」等连续编号，核对与基本设计的对应关系。简要说明指定已确认的基本设计。 |
| 成套产品 | 确认产品同一大类、具有共同设计构思且习惯上成套出售或使用。核对各件整体外观，按「套件1主视图」等命名，必要时说明各套件产品名称。 |
| 组件产品 | 组装关系唯一时核对组合状态视图。组装关系不唯一或无组装关系时核对各组件视图，以「组件1主视图」等标识归属。 |
| 图形用户界面 | 名称与简要说明交代界面的具体用途和所应用的产品。核对整体或局部图样的适用方式，有无载体依已确认的方案与指南判断。动态界面以涉及起始状态的视图为主视图，按变化先后编排关键帧及说明。 |

按设计实际所需视图核对充分性，在简要说明中写明省略视图及具体原因。请求保护色彩时核对用户确认的色彩图样和声明。对于设计要点、保护范围、代表图、图样及媒体附件，核验记录逐项定位到用户确认的源材料。 [外观设计简要说明官方表格](../assets/130002外观设计简要说明.docx) · [专利法实施细则第三十、三十一和四十条](https://www.cnipa.gov.cn/art/2023/12/21/art_98_189197.html) · [图形用户界面申请指引](https://www.cnipa.gov.cn/art/2025/12/5/art_66_202950.html)

## 留存可复核的来源

在核验记录按权项或限定写明「工作稿位置、源文件及段落或图表位置、核对结果」。源文分别记载必要条件和优选条件时，注明它们支持哪个权项、适用哪一种实施方式。遇到缺件或冲突，记下相应原文位置、受影响的权项或分册、需要确认的内容。

按现有文件复核以下容易在重排中改变的细节：

- 公式中的上标、下标、比较符号、括号、单位及公式前后的相关正文。
- 表格的行列对应、数值及注释，特别是表头限定的条件、单位与范围。
- 附图和说明书的图号、标记、图题，以及请求书指定的摘要附图图号。
- 权项的前后引用、必要和可选组合，以及说明书中支撑每项限定的具体位置。
